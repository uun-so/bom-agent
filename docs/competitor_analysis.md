# BOM‑Agent 竞品分析

## 一、调研目的
本次调研围绕制造业BOM物料管理、ECN工程变更场景下的相关产品与解决方案，梳理各类竞品的能力边界、优势与短板，辅助本项目技术与产品路线决策，明确BOM‑Agent差异化定位，聚焦项目核心价值。

## 三、竞品总结
当前市面上主流方案分为三类：重型ERP/PLM系统能力全面但笨重昂贵，AI‑BOM工具聚焦物料识别但缺少变更连锁推演能力，低代码Agent平台原型搭建快，但制造业业务适配深度不足。

绝大多数产品没有专门针对**ECN工程变更场景下多层BOM上下游连锁风险自动评估**打造轻量化智能体。

## 四、BOM‑Agent差异化定位
BOM‑Agent是面向制造业ERP物料管理场景的轻量化Agent POC原型。
✅ 核心目标：接收零部件变更需求，自动查询多层BOM清单，推导上下游零部件连锁影响，输出风险评估报告
✅ 定位：ERP外挂AI助手，不替代原有企业管理系统，聚焦ECN变更影响评估痛点，弥补现有产品AI推演能力短板
✅ 核心优势：轻量化、快速POC验证，针对性处理BOM场景AI幻觉问题，专注变更连锁影响推演

## 五、后续迭代思考
基于竞品暴露出来的痛点，在v2版本中可以继续优化：
1. 完善物料别名、MPN识别与校验逻辑，进一步抑制AI幻觉
2. 丰富风险评估维度，增加生产、采购侧风险提示
3. 预留接口，支持和主流ERP、PLM做数据对接
